# Integrated-Business-Data-Analytics-and-Executive-Decision-Support-Using-Big-Data-Technologies
An end-to-end Big Data project that integrates telecommunications and financial datasets using PySpark, Parquet, HDFS, and Apache Hive to build a unified executive dashboard for customer analytics, churn prediction, financial risk, compliance, and business performance.
A holding company owns two subsidiaries:

Telecommunications Company
Dataset: Telco Customer Churn
Financial Services Company
Dataset: Financial Risk & Compliance

The executive management needs a centralized platform to monitor the overall performance of both companies and support strategic decision-making.

Project Objectives

The project aims to:

Integrate data from multiple business sectors.
Build a scalable ETL pipeline using PySpark.
Store processed data in Parquet format.
Manage distributed storage using HDFS.
Create analytical tables with Apache Hive.
Deliver an executive dashboard for data-driven decision support.
